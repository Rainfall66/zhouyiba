    游戏规则

    系统随机选一个目标,你输入名称,每次猜测会新增一行,逐属性给出反馈。

    反馈颜色(猜干员)

    • 绿色(命中) —— 阵营 / 职业 / 性别与答案相同;身高 / 年龄与答案完全一致
    • 黄色(接近) —— 身高相差 3cm 以内、年龄相差 1 岁以内(都会附 ▲▼ 箭头)
    • 灰色 —— 与答案不同,或该属性为未知("-")
    • 箭头 —— ▲ 表示答案的数值更高,▼ 表示更低

    属性说明

    • 阵营:GTI / 哈夫克 / 无(无名无阵营);职业:突击 / 工程 / 支援 / 侦察;性别:男 / 女
    • 身高 / 年龄:官方档案数值(未公布的按未知处理)
    • 登场赛季 / 本名 / 称号 / CV 等档案:不上棋盘,结算时展示
    • 拼音联想:输入全拼或首字母也能找到干员(如 hl → 红狼),或直接输入英文代号(如 D-Wolf)。拼音仅用于联想,需点选候选项后再提交

    胜负

    干员名猜对即胜;6 次仍未猜中或主动查看答案则失败。

    反馈颜色(猜武器)

    • 绿色(命中) —— 类型 / 口径与答案相同;射击模式与答案完全一致;伤害 / 射速 / 弹匣与答案完全一致
    • 黄色(接近) —— 射击模式与答案有共同项(如答案是「全自动/单发」,你猜「全自动/两连发」);伤害相差 2 以内、射速相差 30 RPM 以内、弹匣相差 5 发以内(数值附 ▲▼ 箭头)
    • 灰色 —— 与答案不同,或该属性为未知("-")
    • 箭头 —— ▲ 表示答案的数值更高,▼ 表示更低

    属性说明

    • 两个卡池:烽火地带 / 全面战场 各自独立抽答案;伤害按所选模式取值(同一把武器在两个模式数值可能不同)
    • 类型:突击步枪 / 冲锋枪 / 机枪 / 狙击枪 / 射手步枪 / 霰弹枪 / 手枪
    • 口径:如 5.56×45mm / 7.62×39mm / 9×19mm / 12Gauge 等
    • 伤害 / 射速 / 弹匣:基础数值(默认弹匣,不含配件)
    • 霰弹枪伤害:棋盘显示「单弹丸×弹丸数」(如 14×8),命中判定按总伤比对;FS12 有泵动/半自动两档数值,按半自动档记录(见结算页备注)
    • 拼音联想:输入全拼或首字母也能找到武器,需点选候选项后再提交

    胜负

    武器名猜对即胜;8 次仍未猜中或主动查看答案则失败。
