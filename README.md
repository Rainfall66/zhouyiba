# 洲一把 · 三角洲行动干员/武器猜测游戏(单机版)

> **非官方粉丝作品** —— 与《三角洲行动 Delta Force》及其开发 / 发行方(腾讯天美工作室群)无关。
> 猜角色 / 猜物品类 Wordle 玩法:输入名称,根据逐属性颜色反馈,在限定次数内猜出目标。

纯静态、零依赖、双击即玩:浏览器打开 `index.html` 就能玩,无需 Node / 数据库 / 联网。

> **数据现状(2026-10-01,对齐 S11「群星」赛季)**:猜武器收录 **68 把武器**(烽火地带 / 全面战场
> 两个子模式卡池各 68 把)、猜干员收录 **17 名干员**(公测 8 人 + S3~S11 各 1 人)。
> 全面战场伤害已**全部收录(68/68)**,棋盘「伤害」列不再出现未知「-」:
> 其中 16 把来自社区计算器数据集并做了双源交叉核对;2026-10-01 新增 M82=100;
> 剩余 7 把(M16A4=25、杠杆式步枪=54、725=272、M870=240、S12K=136、M1014=160、93R=25)
> 经腾讯官方文章 / palygamer 战场表 / zilliongamer 面板等来源补全;
> 2026-10-01 玩家修正:R93 战场伤害 **100**(原 74 有误)、FS12 半自动 18×8=144 / 泵动 25×8=200(两模式相同)。
> —— 详见下方「伤害数值的未知语义」与 `pipeline/README.md` 的补充调研记录。

## 双模式

开始页先**选模式**,再按「开始游戏」开局(按钮文案会显示当前选择):

- **▲ 猜干员**(6 次机会)—— 选中后直接开局,卡池来自 `operators.js`;
- **◆ 猜武器**(8 次机会)—— 选中后需再选子模式「烽火地带 / 全面战场」(默认烽火地带)。
  两个独立卡池由每条武器记录的 `模式` 字段(通用 / 仅烽火地带 / 仅全面战场)过滤;
  伤害按所选模式取值:烽火地带读 `伤害`,全面战场读 `战场伤害`。

开始页还可以勾选 **每日一题**:当天所有玩家抽到同一目标(按 `日期 + 模式 + 子模式` 散列选目标),
每种模式每天记录一次成绩。

### 伤害数值的未知语义(2026-09-30 修订,重要)

`战场伤害` 为 `null` 表示**该模式数值未收录**,而不是「与烽火数值相同」:

- 棋盘显示未知「-」,判定为灰,**不参与 ±2 容差判定**,也不出 ▲▼ 箭头;
- 状态行会提示本局卡池里有多少把武器的伤害未收录(截至 2026-10-01 已为 **0 把**,该提示自然消失);
- 若某把武器**确认**两模式数值相同,可直接写相同数值;也可显式写 `战场伤害同烽火: true`(此时取 `伤害` 值)。
  当前 68 把均已写入独立数值,**数据里已无 `同烽火` 条目**(FS12 曾用该标记,2026-10-01 起改为直接写值);
- 修订原因:原始调研 68 条里**没有任何一条** `damageWarfare === damageOps`,旧版「留空 = 相同」会把
  没有信源的枪显示成实测值;
- 补值办法见 `pipeline/README.md`「全面战场伤害补充调研」:主源是社区计算器数据集
  (其 M1911 = 35 与游戏内实测一致),并用 2024 年的全面战场数据表交叉核对,冲突项记录在案不改数据。

## 玩法

- 系统从所选卡池随机选一个目标(1 小时内不重复抽到已猜过的目标,按模式分别记忆);
- 输入名称(带自动补全),每次猜测新增一行逐属性反馈;
- 🟩 **绿色(命中)** —— 精确类属性与答案相同;数值类属性与答案**完全一致**
- 🟨 **黄色(接近)** —— 集合类属性**有共同项**;数值进入容差区间(附 ▲▼ 箭头)
- ▲▼ **箭头** —— 提示答案的数值更高 / 更低
- ➖ **"-"** —— 未知属性(数据未录入的),对比按灰色处理,鼠标悬停有说明
- **搜索别名**:支持别名 / 称号联想,别名与拼音都支持**数组**写法(多别名、多音、常见误拼)
- **拼音联想**:输入**全拼或首字母**都能找到目标;拼音仅用于联想,需**点选候选项**或**直接回车**提交
- 🖼 **图片** —— `avatar` 有值时,候选与猜测行显示小头像,结算弹窗放大展示;留空或加载失败自动隐藏
- **每日一题 / 随机开局** 二选一;战绩分模式存档,开始页可查看胜率与最高连胜,也可一键清零
- **对局续存** —— 未完成的对局存在 `sessionStorage`,刷新或误点返回后可从开始页「继续上一局」
- **复制战绩** —— 结算弹窗「复制战绩」生成 Wordle 式 emoji 网格(🟩🟨⬛)便于分享
- 猜中名称即胜;次数用尽或主动查看答案即失败

### 键盘操作

| 按键 | 行为 |
|---|---|
| `Enter` | 提交猜测;若输入不完整(如只打了拼音),**采纳当前高亮候选并提交** |
| `↑` / `↓` | 在候选列表里移动高亮(同时填入输入框) |
| `Tab` | 把当前高亮候选填入输入框(不提交) |
| `Esc` | 关闭规则 / 结算弹窗 |

### 棋盘列

**猜干员**(6 列,6 次机会):

| 列 | 判定方式 | 取值 |
|---|---|---|
| 阵营 | 精确 | GTI / 哈夫克 / 无(无名无阵营) |
| 职业 | 精确 | 突击 / 工程 / 支援 / 侦察 |
| 性别 | 精确 | 男 / 女 |
| 身高 | 数值(±3cm 黄) | 官方档案 cm 值 |
| 年龄 | 数值(±1 岁 黄) | 官方档案岁值 |

> 登场赛季 / 称号 / 技能标签**不上棋盘**,在结算页展示。

**猜武器**(7 列,8 次机会):

| 列 | 判定方式 | 取值 |
|---|---|---|
| 类型 | 精确 | 突击步枪 24 / 冲锋枪 12 / 射手步枪 10 / 手枪 7 / 狙击枪 5 / 霰弹枪 5 / 机枪 4 / 特殊武器 1 |
| 口径 | 精确 | 5.56×45mm / 7.62×39mm / 9×19mm / 12Gauge … |
| 射击模式 | 集合(有共同项=黄) | 全自动 / 半自动 / 泵动 / 栓动 / 单发 / 两连发 / 三连发 |
| 伤害 | 数值(±2 黄,按子模式取值) | 烽火地带读 `伤害`;全面战场读 `战场伤害`(未收录显示「-」);霰弹枪显示「单弹丸×弹丸数」(如 14×8),比对按总伤 |
| 射速 | 数值(±30 RPM 黄) | RPM |
| 弹匣 | 数值(±5 发 黄) | 基础弹匣(不含配件) |

## 数据填充指南

### 干员(`operators.js` → `window.ZHOUYIBA_OPERATORS`)

```js
{ id: 1,
  nickname: "红狼",          // 干员名(游戏内代号),提交判定以它为准
  alias: "D-Wolf",           // 英文代号,搜索联想用,也可直接提交(支持数组:["D-Wolf","红狼"])
  可用: true,                // false = 仅存档,不参与对局
  阵营: "GTI",               // GTI / 哈夫克 / 无(无名无阵营)
  职业: "突击",              // 突击 / 工程 / 支援 / 侦察
  性别: "男",
  登场赛季: "公测",          // 公测 / S3 ~ S11(结算页展示)
  身高: 183, 年龄: 29,       // 棋盘数值列;未知填 null
  本名: "凯·席尔瓦 Kai Silva", // 结算页展示
  称号: "单兵外骨骼首个使用者", // 结算页展示(可空)
  备注: "GTI 北美分部 · CV 青琳昊", // 结算页展示(可空)
  标签: [],                  // 技能 / 道具关键词(备查,不上棋盘)
  pinyin: "honglang", pinyinAbbr: "hl",   // 也支持数组,见下
  avatar: "images/head-honglang.webp", images: ["images/art-honglang.webp"] }
```

`pinyin` / `pinyinAbbr` 支持**字符串或数组**:数组用于多音字与常见误拼,例如
骇爪 `["haizhua", "huaizhua"]`(正确拼音 + 历史笔误都保留)、旅人 `["lvren", "luren"]`。

### 武器(`weapons.js` → `window.ZHOUYIBA_WEAPONS`)

> 该文件由 `pipeline/gen_weapons.js` 生成(`npm run gen:weapons`),手改会在下次生成时被覆盖;
> 改数值优先改生成脚本里的 `CORRECTIONS`。生成结果与仓库文件**逐字节一致**,可放心重跑。

```js
{ id: 1,
  nickname: "CAR-15",        // 武器名(游戏内名称)
  alias: "", 可用: true,
  模式: "通用",              // 通用 / 仅烽火地带 / 仅全面战场 —— 决定进哪个子模式卡池
  类型: "突击步枪",          // 精确匹配列
  口径: "5.56×45mm",         // 精确匹配列
  射击模式: ["全自动", "单发"], // 集合匹配列
  伤害: 26,                  // 烽火地带基础伤害
  战场伤害: 24,              // 全面战场基础伤害;null = 该模式未收录(棋盘显示「-」)
  战场伤害同烽火: false,      // true = 已确认两模式数值相同,此时取「伤害」值
  伤害明细: "13×8",          // 霰弹枪专用:面板显示「单弹丸×弹丸数」,比对仍按「伤害」总伤(非霰弹枪为 null)
  射速: 780,                 // RPM
  弹匣: 30,                  // 基础弹匣
  有效射程: null, 备注: "",  // 结算页展示(可空)
  pinyin: "car15", pinyinAbbr: "",
  avatar: "", images: [] }
```

- **官方未公布的属性留空**(`""` 或 `null`),对局中显示灰 "-",不影响游玩;
- 头像图片放进 `images/`,文件名统一用 **ASCII 拼音 slug**;加载失败会自动隐藏,不会出现破图;
- 当前已随库附图:干员头像 `head-*.webp` 16/17、立绘 `art-*.webp` 16/17(旅人两者皆缺;
  回响 / 液氮的头像是从各自立绘顶部自动裁切生成的),武器官方图标 `w-*.webp` 64/68
  (MDR / 汤姆逊 / FS12 / 复合弓 暂缺,游戏对缺图自动降级),另有分享封面 `og-cover.png`;
- 改完保存刷新即生效。

## 技术说明

- 纯原生 HTML/CSS/JavaScript,无框架、无构建、无外部依赖,支持 `file://` 直接打开;
- **逻辑与界面分离**:`core.js` 零 DOM 依赖(浏览器挂 `window.ZHOUYIBA`,node 走 `module.exports`),
  `app.js` 只做渲染与事件,因此核心规则可以被 node 单测直接覆盖;
- **模式化架构**:棋盘列 / 判定规则 / 卡池 / 文案全部由 `core.js` 顶部的 `MODES` 配置驱动,
  表头动态渲染(`data-mode` 属性驱动列宽 CSS),新增模式只需加一份配置;
- **移动端自适应**:棋盘在窄屏自动收紧字号与列宽(干员 6 列 / 武器 7 列各有再平衡),
  底部输入坞(键盘弹起自动贴底)、安全区适配与大触控目标;
- **图片分两类处理**:干员头像是方形特写,用 `object-fit: cover` + `object-position: 50% 18%` 取头部;
  武器官方图标是 **2:1 横版透明底产品图**(512×256),改用 `contain` + 2:1 缩略框完整显示整把枪
  (桌面 46×23 / 窄屏 34×17),否则方形裁切只会露出枪身中段;
  结算页在没有立绘时回退显示该图标(`pickPortrait` 先取 `images`、为空再取 `avatar`);
- 判定规则:精确(相同绿/不同灰)、集合(完全相同绿/有交集黄)、数值(相同绿/容差内黄+▲▼);
  任一方属性为空(含 `Number(null)` 陷阱)都按未知灰处理,不出错误箭头;
- **未知 ≠ 相同**:未收录的模式数值是 `null`(棋盘 "-");只有显式 `战场伤害同烽火: true` 才沿用烽火数值(当前无此类条目);
- **存档分层**:战绩按「模式 + 子模式」分桶(`zhou-yiba:stats:weapon:ops` 等)并另存跨模式总计
  (`zhou-yiba:stats`),最近目标按模式分键(`zhou-yiba:recent:*`,1 小时窗口),未完成对局存
  `sessionStorage`(`zhou-yiba:session`),每日一题成绩存 `zhou-yiba:daily`;存档读写全部 try/catch,
  无痕模式或禁用存储时静默降级不影响游玩;
- **每日一题**:FNV-1a 散列 `日期 + 模式 + 子模式` 选目标,同一台设备/任意浏览器结果一致,无需服务端;
- **可访问性**:弹窗有 `role="dialog"` + `aria-modal` + 焦点进入/归还 + `Tab` 圈闭,输入框是标准
  `combobox`(`aria-expanded` / `aria-activedescendant`)配 `listbox`,表头带 `scope="col"`,提示条是
  `role="status"`,子模式是 `radiogroup`(方向键切换),键盘有可见焦点环;
- **CSP 友好**:页面无内联 `<script>` / 内联事件处理器 / 内联 `style`(颜色走 CSS 类),头像加载失败
  用事件委托处理(单测会检查这些约束);
- **空数据守卫**:某个模式卡池为空(或全部「仅存档」)时,开始该模式只弹提示并告警,
  不会白屏、不会报错,也**不会静默回退成包含不可用条目的卡池**。
