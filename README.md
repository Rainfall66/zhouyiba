# 洲一把 · 三角洲行动干员/武器猜测游戏(单机版)

> **非官方粉丝作品** —— 与《三角洲行动 Delta Force》及其开发 / 发行方(腾讯天美工作室群)无关。
> 猜角色 / 猜物品类 Wordle 玩法:输入名称,根据逐属性颜色反馈,在限定次数内猜出目标。

纯静态、零依赖、双击即玩:浏览器打开 `index.html` 就能玩,无需 Node / 数据库 / 联网。

> **数据现状(2026-09-29,对齐 S11「群星」赛季)**:猜武器已收录 **68 把武器**(两模式卡池各 68,
> 复合弓为全面战场突击兵/侦察兵的特殊武器)、猜干员已收录 **17 名干员**(公测 8 人 + S3~S11 各 1 人)。
> 数值/档案调研详情见 `pipeline/README.md`。

## 双模式

开始页先**选模式**,再按「开始游戏」开局(按钮文案会显示当前选择):

- **▲ 猜干员**(6 次机会)—— 选中后直接开局,卡池来自 `operators.js`;
- **◆ 猜武器**(8 次机会)—— 选中后需再选子模式「烽火地带 / 全面战场」(默认烽火地带)。
  两个独立卡池由每条武器记录的 `模式` 字段(通用 / 仅烽火地带 / 仅全面战场)过滤;
  伤害按所选模式取值:烽火地带读 `伤害`,全面战场优先读 `战场伤害`(留空则视为相同)。

战绩与「最近猜过」按 模式(及武器子模式)分开存档,互不干扰。

## 玩法

- 系统从所选卡池随机选一个目标;
- 输入名称(带自动补全),每次猜测新增一行逐属性反馈;
- 🟩 **绿色(命中)** —— 精确类属性与答案相同;数值类属性与答案**完全一致**
- 🟨 **黄色(接近)** —— 集合类属性**有共同项**;数值进入容差区间(附 ▲▼ 箭头)
- ▲▼ **箭头** —— 提示答案的数值更高 / 更低
- ➖ **"-"** —— 未知属性(数据未录入的),对比按灰色处理
- **搜索别名**:支持别名 / 称号联想
- **拼音联想**:输入**全拼或首字母**都能找到目标。拼音仅用于联想,需**点选候选项**后再提交
- 🖼 **图片** —— `avatar` 有值时,候选与猜测行显示小头像,结算弹窗放大展示;留空或加载失败自动隐藏
- 猜中名称即胜;战绩与最近目标保存在本机浏览器(localStorage)

### 棋盘列

**猜干员**(6 列,6 次机会):

| 列 | 判定方式 | 取值 |
|---|---|---|
| 阵营 | 精确 | GTI / 哈夫克 / 无(无名无阵营) |
| 职业 | 精确 | 突击 / 工程 / 支援 / 侦察 |
| 性别 | 精确 | 男 / 女 |
| 身高 | 数值(±3cm 黄) | 官方档案 cm 值 |
| 年龄 | 数值(±1 岁 黄) | 官方档案岁值 |

> 登场赛季 / 称号 / 技能标签**不上棋盘**,在结算页展示。

**猜武器**(7 列,8 次机会):

| 列 | 判定方式 | 取值 |
|---|---|---|
| 类型 | 精确 | 突击步枪 / 冲锋枪 / 机枪 / 狙击枪 / 射手步枪 / 霰弹枪 / 手枪 |
| 口径 | 精确 | 5.56×45mm / 7.62×39mm / 9×19mm / 12Gauge … |
| 射击模式 | 集合(有共同项=黄) | 全自动 / 单发 / 两连发 / 三连发 / 栓动 … |
| 伤害 | 数值(±2 黄,按子模式取值) | 烽火地带读 `伤害`;全面战场优先读 `战场伤害`;霰弹枪显示「单弹丸×弹丸数」(如 14×8),比对按总伤 |
| 射速 | 数值(±30 RPM 黄) | RPM |
| 弹匣 | 数值(±5 发 黄) | 基础弹匣(不含配件) |

想增删列:改 `app.js` 里对应模式的 `columns` 配置(含 `close` 容差),与
`style.css` 的 `table.board[data-mode=…]` 列宽保持一致即可;表头由 JS 按模式动态渲染,无需改 HTML。

  登场赛季: "公测",          // 公测 / S3 ~ S11(结算页展示)

  本名: "凯·席尔瓦 Kai Silva", // 结算页展示

  备注: "GTI 北美分部 · CV 青琳昊", // 结算页展示(可空)

  pinyin: "honglang", pinyinAbbr: "hl",

### 武器(`weapons.js` → `window.ZHOUYIBA_WEAPONS`)

```js
{ id: 1,
  nickname: "CAR-15",        // 武器名(游戏内名称)
  alias: "", 可用: true,
  模式: "通用",              // 通用 / 仅烽火地带 / 仅全面战场 —— 决定进哪个子模式卡池
  类型: "突击步枪",          // 精确匹配列
  口径: "5.56×45mm",         // 精确匹配列
  射击模式: ["全自动", "单发"], // 集合匹配列
  伤害: 26,                  // 烽火地带基础伤害
  战场伤害: 24,              // 全面战场基础伤害;留空 = 与「伤害」相同
  伤害明细: "13×8",          // 霰弹枪专用:面板显示「单弹丸×弹丸数」,比对仍按「伤害」总伤(非霰弹枪省略)
  射速: 780,                 // RPM
  弹匣: 30,                  // 基础弹匣
  有效射程: null, 备注: "",  // 结算页展示(可空)
  pinyin: "car15", pinyinAbbr: "",
  avatar: "", images: [] }
```

- **官方未公布的属性留空**(`""` 或 `null`),对局中显示灰 "-",不影响游玩;
- 头像图片放进 `images/`,文件名统一用 **ASCII 拼音 slug**;加载失败会自动隐藏,不会出现破图;
- 当前已随库附图:干员头像 `head-*.webp` + 立绘 `art-*.webp`(16/17,旅人暂缺)、
  武器官方图标 `w-*.webp`(64/68,MDR/汤姆逊/FS12/复合弓暂缺,游戏对缺图自动降级);
- 改完保存刷新即生效。

## 技术说明

- 纯原生 HTML/CSS/JavaScript,无框架、无构建、无外部依赖,支持 `file://` 直接打开;
- **模式化架构**:棋盘列 / 判定规则 / 卡池 / 文案全部由 `app.js` 顶部的 `MODES` 配置驱动,
  表头动态渲染(`data-mode` 属性驱动列宽 CSS),新增模式只需加一份配置;
- **移动端自适应**:棋盘在窄屏自动收紧字号与列宽(干员 6 列 / 武器 7 列各有再平衡),
  底部输入坞(键盘弹起自动贴底)、安全区适配与大触控目标;
- 判定规则:精确(相同绿/不同灰)、集合(完全相同绿/有交集黄)、数值(相同绿/容差内黄+▲▼);
  任一方属性为空(含 `Number(null)` 陷阱)都按未知灰处理,不出错误箭头;
- **空数据守卫**:某个模式卡池为空时,开始该模式只弹提示,不会白屏或报错。

## 主题与配色

- **主色调**:军械橙 `#ff9420` + 枪铁暗底 `#0b0d10`,辅以 GTI 青 `#35b8d0`、哈夫克红 `#e0483e`;
- **视觉母题**:三角(Δ)徽记 —— 品牌旁的 ▲、开始页背景大三角、棋盘上方的三角进度标记;
- 反馈色沿用系列惯例:命中绿 `#3fd46c` / 接近金 `#ffc94d`,与军械橙区分开。
